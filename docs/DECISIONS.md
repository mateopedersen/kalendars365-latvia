# Decisions

- New isolated project, no changes to existing sites.
- Jekyll static HTML with Ruby date generation, browser-local personal records and downloads.
- Sources that cannot be verified remain explicitly pending and noindex.
- No third-party analytics or ads, no paid service provisioning.
- Actual Cloudflare domain must be verified before production canonical is selected.
- Official downloads currently advertise Ruby 4.0.8; bundle compatibility will be tested rather than trusting packet version 4.0.7.
